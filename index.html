Featured project

Charger Licence Fee Management

Recurring billing and access control for privately assigned EV chargers in residential buildings. Fees were collected by hand, with no reminders, no enforcement and no record of user consent. I owned the feature end to end, from requirement analysis to live testing on a real charger.

TypeScriptNestJSTypeORMPostgreSQL + RLSKafka + AvroRedisOCPP 1.6AWS SNSKubernetesJest

The licence lifecycle

Configure

Monthly or yearly fee with bounds; edits apply at next renewal.

Bill in advance

On the 1st, in the site's timezone, from the primary then secondary wallets.

Remind & retry

Daily retries plus email, push and in-app alerts.

Grace period

Time to pay before any access is affected.

Block remotely

Charger set inoperative over OCPP via Kafka.

Auto-reinstate

Payment or wallet top-up unblocks it automatically.

No double charges, ever

Each billing period gets a deterministic UUID v5 transaction id. The wallet rejects repeats with HTTP 409, so retries, crashes and concurrent triggers can never charge a resident twice.

Self-healing charger state

The system tracks desired versus confirmed charger state and re-sends lost OCPP commands automatically. Admins can unblock for 24 hours; it re-blocks if still unpaid.

Safe scheduled jobs

A daily billing job and a 10-minute sweep run on one pod via leader election and Redis locks. Every step is crash-safe and restartable.

Consent and invoicing

Versioned Terms and Conditions with append-only consent records, enforced at session start, plus PDF invoices with signed download links.
